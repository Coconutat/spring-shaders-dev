# ADR-0004: 路径追踪与彩色光源互斥设计

**状态**: 已采纳  
**日期**: 2024  
**作者**: 中影 / ZYPanDa

## 背景

体素锥追踪可以用于两种不同的光照计算：路径追踪全局光照（物理正确多次弹射）和彩色光源扩散（方块颜色光照传播）。两者都依赖体素数据结构，但算法不同，不能同时开启。

## 决策

### 互斥设计

`PATH_TRACING` 和 `COLORED_LIGHT` 不能同时定义。UI 中通过同一个 `path_tracing_colored_light` 面板控制，警告用户"不能和光线追踪漫反射同时开启"。

### 共享资源

两者共享相同的体素纹理基础设施（`customimg0/4/5/6`），但路径追踪额外需要 `customimg1/2/3`（tmpX/tmpY/SDF）。

### 共同的依赖 program

两者都需要同步启用以下 program，否则依赖缓冲缺失：
- `begin` (体素初始化)
- `shadowcomp_a/b/c`、`shadowcomp`、`shadowcomp1_a/b` (阴影合成)
- `deferred6`、`deferred7`、`deferred8` (体素相关 deferred pass)

## 权衡

| 选项 | 优点 | 缺点 |
|------|------|------|
| **互斥 (选定)** | 清晰的责任边界；无需运行时分支调度；体素纹理格式固定 | 用户不能同时享受两种效果；需要切换时重启光影 |
| **合并为一个算法** | 统一实现 | 两者的目标不同（物理 GI vs 艺术化光照），合并会损害质量 |
| **运行时切换** | 无重载延迟 | GLSL 条件分支导致性能损失；编译变体增加 |

## 影响

- `PATH_TRACING_QUALITY` 同时控制路径追踪的射线数量和彩色光源的质量。
- `DEFERRED10_PT_ALBEDO_SCALE` 专用于路径追踪开启时的无光照基础亮度。
- `DEFERRED10_ALBEDO_SCALE` 用于普通延迟光照分支。
